# 💰 Student Expense Tracker

A simple and user-friendly expense management application designed for students to track their daily spending and manage their monthly budget.

## ✨ Features

- ➕ Add new expenses
- 📋 View all expenses
- 🗑️ Delete expenses
- 💰 Calculate total expenses
- 🎯 Set monthly budget
- 📊 Category-wise expense analysis
- 📈 Spending analytics
- 🔎 Search expenses
- 💾 Persistent data storage using LocalStorage
- 📱 Responsive design

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript
- LocalStorage
